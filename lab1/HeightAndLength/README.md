## Что делает программа

Пользователь вводит длину, единицы, в которых он её ввёл, и выбирает единицы, в которые её нужно перевести.
Поддерживаются единицы:

| Единица | 1 единица в метрах | Откуда значение |
|---|---|---|
| Дюйм | 0,0254 | точно 2,54 см |
| Ярд | 0,9144 | точно 91,44 см |
| Сантиметр | 0,01 | 1/100 метра |
| Метр | 1 | базовая единица СИ |
| Американский таракан | 0,04 | средняя длина взрослого Periplaneta americana ≈ 4 см |
| Шея жирафа | 1,8 | средняя длина шеи взрослого жирафа ≈ 1,8 м |
| Самая длинная змея | 7,67 | рекордный сетчатый питон (Книга рекордов Гиннесса) |
| Человеческий язык | 0,10 | средняя длина языка взрослого человека ≈ 10 см |
| Футбольное поле | 105 | стандартная длина поля по рекомендации FIFA |

- На главной форме кнопка **«Ввести данные»** открывает отдельное окно ввода.
- Последние введённые данные показываются на главной форме, подставляются в окно ввода при повторном
  вводе и сохраняются между запусками (`java.util.prefs`).
- На главной форме выводится результат и та же длина во всех единицах.
- При некорректном вводе (пусто, не число, ноль или отрицательное, больше 10¹²) показывается сообщение
  об ошибке, окно ввода остаётся открытым.

## Архитектура: MVC с активной моделью

| Пакет | Классы | Роль |
|---|---|---|
| `model` | `ConversionModel`, `Conversion`, `ConversionInput`, `LengthUnit`, `InputParser`, `InputStorage`, `InvalidInputException` | данные, правила проверки, пересчёт, хранение; **модель сама оповещает подписчиков** через `PropertyChangeSupport` |
| `view` | `MainFrame`, `InputDialog`, `NumberFormats` | главное окно подписано на модель (`PropertyChangeListener`) и перерисовывается по её сигналу; окно ввода только собирает данные |
| `controller` | `ConversionController` | обрабатывает нажатия кнопок, проверяет ввод, передаёт данные модели; главное окно не обновляет |
| `app` | `Main` | точка входа, связывает три части |

Диаграммы: `docs/mvc-class-diagram.puml` (классы) и `docs/mvc-sequence.puml` (последовательность ввода данных).

## Запуск

1. IntelliJ IDEA → **File → Open** → папка `HeightAndLength`.
2. Если IDEA попросит выбрать SDK — указать JDK 17 или новее (**File → Project Structure → Project → SDK**).
3. Запустить конфигурацию **Main** (класс `app.Main`).

## Отладка

Удобные точки останова: `ConversionController.submit` (проверка ввода) и `Conversion.convert` (пересчёт).
Запуск под отладчиком — **Run → Debug 'Main'**.
